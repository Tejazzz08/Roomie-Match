# RoomieMatch

A polished, responsive frontend concept for finding compatible student roommates.

## Run locally
1. Install Node.js (18 or newer recommended).
2. Open this folder in a terminal.
3. Run `npm install`
4. Run `npm run dev`
5. Open the local URL printed by Vite (usually http://localhost:5173).

## What's included
- Discover page with student cards, search, filters and compatibility estimates.
- Detailed roommate profiles with academics, CGPA, budget, interests and lifestyle preferences.
- Filters for budget, smoking, drinking, sleep schedule, food preference and cleanliness.
- Save profiles, mark interest, and view Saved / Matches tabs.
- Editable profile form covering course, year, CGPA, budget, hometown, interests, sleep, cleanliness, study environment, smoking, drinking, food preference, guests, noise, AC and daily routine.
- Responsive desktop and mobile layouts.
- Profile data is saved in browser localStorage.

## Important demo limitations
This is a frontend-only project. The student profiles are sample data and the compatibility percentage is illustrative, not a scientifically validated score. There is no real login, database, messaging, identity verification or academic-record verification. Do not enter sensitive personal information. For a real deployment, add a secure backend, consent/privacy controls, moderation, reporting/blocking and verified student accounts.
